# Shared Team Rules

## Daily Sync

15-minute meeting:

1. What did I finish?
2. What am I doing next?
3. What is blocking me?

## Shared Definition of Done

No feature is considered complete until:
- implemented;
- integrated;
- tested;
- documented;
- demo-ready.

## Ownership Principle

Each person owns their module, but **no module is allowed to become a silo**. Every phase ends with an integration checkpoint.
