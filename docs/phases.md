# Development Phases

## Phase 0 — Scope Freeze

### Objective
Define exactly what will be demonstrated.

### Tasks
- finalize problem;
- finalize MVP;
- define personas;
- freeze tech stack;
- define demo script.

### Exit Criteria
- PRD approved;
- feature scope frozen;
- responsibilities assigned.

---

## Phase 1 — Architecture and UX

### Objective
Create a shared technical and visual foundation.

### Tasks
- wireframes;
- route map;
- database schema;
- API contract;
- component design;
- repository setup.

### Exit Criteria
- frontend routes exist;
- backend skeleton runs;
- database migrations/schema ready.

---

## Phase 2 — AI Recommendation

### Objective
Deliver the main innovation.

### Tasks
- prepare crop data;
- implement crop scoring;
- integrate weather;
- calculate risk;
- estimate profit;
- expose recommendation API;
- build recommendation UI.

### Exit Criteria
A farmer can enter farm information and receive ranked recommendations.

---

## Phase 3 — Marketplace

### Objective
Connect farmer supply to buyer demand.

### Tasks
- create listings;
- browse listings;
- listing details;
- buyer inquiry/order;
- order status.

### Exit Criteria
Farmer can list produce and buyer can submit an order.

---

## Phase 4 — Admin and Analytics

### Objective
Add platform trust and visibility.

### Tasks
- user verification;
- listing moderation;
- platform metrics;
- market insights;
- analytics dashboard.

### Exit Criteria
Admin can moderate the core marketplace flow.

---

## Phase 5 — Integration and QA

### Objective
Remove blockers.

### Tasks
- API integration;
- end-to-end testing;
- responsive QA;
- error states;
- security checks;
- seed data;
- deployment.

### Exit Criteria
All three major demo journeys work.

---

## Phase 6 — Presentation

### Objective
Convert the product into a compelling hackathon submission.

### Tasks
- pitch deck;
- architecture diagram;
- impact metrics;
- demo script;
- technical explanation;
- future roadmap.

### Exit Criteria
Team can complete the entire demo without manual intervention.
