# AgroConnect 🌱

**AI-powered Crop Planning & Direct Farm-to-Market Marketplace**

AgroConnect is a modern digital platform designed to bridge the gap between farmers and produce buyers. It provides AI-driven crop recommendations based on soil, location, and seasonal market demand, alongside a streamlined marketplace for direct crop listing, buyer discovery, order negotiations, and multilingual support across 10 Indian languages.

---

## 🚀 Key Features

- 🤖 **AI Crop Recommendation Engine**: Input location, soil type, and budget to receive personalized crop recommendations with projected ROI and mandi market trends.
- 🌾 **Produce Marketplace**: Direct listing of harvested crops with quality grading (`Grade A`, `Organic Certified`), quantity in quintals, and asking prices.
- 🛍️ **Buyer Sourcing Portal**: Buyers can browse verified produce listings, filter by district/category, and submit binding purchase inquiries.
- 🗣️ **Multilingual Support**: Fully localized interface in English, Hindi, Kannada, Telugu, Tamil, Marathi, Gujarati, Bengali, Punjabi, and Bodo.
- 📊 **Mandi Price Analytics**: Real-time modal price comparisons and market trend analysis.
- 🛡️ **Admin Governance**: Platform verification workflows for farmers, listings, and trade orders.

---

## 🛠️ Tech Stack

- **Framework**: [Astro v7](https://astro.build/) with static page generation
- **UI Components**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **State Management**: [Nano Stores](https://github.com/nanostores/nanostores)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts & Maps**: Recharts & Leaflet

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/sanjaydsanjay/AgroConnect.git
cd AgroConnect/frontend

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser to view the app.
